# Carmen machine-readable API (v49.4)

See repository root API.md. Machine routes: POST /api/v1/machine/search, POST /api/v1/machine/dive, GET /api/v1/machine/investigations/{id}, GET /api/v1/machine/investigations/{id}/results, POST /api/v1/machine/investigations/{id}/analyze. Auth: X-Carmen-Api-Key or Authorization Bearer with CARMEN_API_KEY. Never send API_KEY. OpenAPI: GET /api/v1/openapi.json.
