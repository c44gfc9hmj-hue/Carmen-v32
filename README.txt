Carmen -v33

Deploy:
1. Open Cloudflare Workers and the Carmen worker.
2. Create a new version or new Worker named Carmen -v33.
3. Choose Edit code.
4. Replace the editor contents with worker.js.
5. Keep the existing API_KEY secret and MODEL/API_URL settings if already configured.
6. Deploy.

Core UX:
- AI-first, conversational home screen
- Search/browse with up to 10 visual results
- Add URL or image
- Save only when explicitly requested
- Open-ended investigations with multiple aspects
- Visual collection/gallery
- Investigations archive
- Tutorials/teachings saved separately and only when requested
- Bottom navigation
- No autonomous external actions
