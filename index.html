Discovery

Give Carmen a person, entity, topic, object, or URL. It classifies the query, searches public sources, and ranks visual candidates — not a generic dump of search-engine links.

Search first, then tap a candidate to select it. Deep Dive expands that candidate with more public sources, images, and OBSERVED / INFERRED / UNKNOWN analysis.

Carmen only reads public information. It never contacts people, sends messages, posts, submits forms, or takes external actions.

Candidates

Run discovery to see ranked public candidates. Each card keeps images, provenance, a match reason, and a Deep Dive action.

Deep dive

Expands the selected candidate: more public sources, retrieved pages, images with provenance, and conservative analysis. Not a repeat of the same keyword search.
