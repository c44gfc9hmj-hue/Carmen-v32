Carmen v49.11 (49.11-exact-source-retrieval) — exact URL retrieval
==================================================================
Parent: 86bdfb2 (v49.9 identity + queue + visual)

Incremental production fix. Extends the v49.9 planner + worker engine.
Does not rebuild Carmen or restyle the UI.

- Analyze receives the exact canonical URL from the source card.
- sourceId = hash(canonicalURL). Two Reddit posts / two OnlyFans profiles
  cannot share an identity.
- Exact URL is fetched first. Generic platform search cannot substitute.
- Reddit permalinks preserve subreddit + post ID. JSON is tried first;
  Pullpush-by-id and Wayback of THAT permalink are fallbacks. Failure copy:
  “Exact Reddit post could not be publicly retrieved.”
- OnlyFans profiles keep handle + exact URL. A generic OnlyFans landing
  page (title/og:url = onlyfans.com) is NOT a profile retrieval — it is
  AUTHENTICATION_REQUIRED. Subscriber content is never bypassed.
- Extracted URLs/accounts/entities become investigation seeds (A → B).
- Source debug object (fetch/parse/auth/seeds/terminalState) is in Deep Dive
  under “Why did Carmen stop?” and “What Carmen actually retrieved.”

Build identifier: **49.11-exact-source-retrieval**.
