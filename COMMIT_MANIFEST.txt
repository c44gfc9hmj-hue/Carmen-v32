Carmen v49.8 (49.8-adaptive-investigation) — adaptive open-ended retrieval
==========================================================================
Parent: 7735a2e3a3dbea12d271072c840c2167b41fe65f (v49.7 retrieval-engine)

Carmen is an investigation engine. It keeps expanding until meaningful
identity variants, topic variants, visual branches, account paths, and
link chains are exhausted — or a real resource/access guard requires
stopping. A raw request count is a safety rail, not the stop logic.

Visual retrieval is a first-class branch seeded from entity evidence.
Concept classification drives discovery queries (frog-tie visual/tutorial).
Account/Premium investigates public profiles with provenance. Belle
Delphine identity collision is enforced before visual ranking.
“Why did you stop?” distinguishes exhausted / no-novelty / provider /
resource-guard / access-boundary.

No architecture rewrite. Extends the existing planner + worker engine.

Build identifier: **49.8-adaptive-investigation**.
